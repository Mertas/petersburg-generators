# Итерация 2 — Глубина: типы жильцов, персонал, улучшения, сезоны

## Что уже есть (из Итерации 1)

- Ядро игры: ходы, квартплата, расходы, 5 событий
- Случайный сид при старте
- Расширение этажей (3 → 5, 2000 ₽ за этаж)
- Баблы с именами жильцов у окон
- Журнал событий, панель ресурсов, модалка события

## Цель

Расширить ядро игры: разныя сословия жильцов со своими эффектами, наём персонала, система улучшений дома, влияние сезонов, сохранение/загрузка, интерактивные баблы и первые визуальные отклики фасада на состояние дома.

---

## 1. Что получаем на выходе

- **5 типов жильцов** — купец, чиновник, студент, художник, рабочий (каждый с уникальными свойствами)
- **Персонал** — дворник, управляющий, швейцар (наём и увольнение)
- **Улучшения** — ремонт фасада, новая крыша, водопровод, газовое освещение, брандмауэр
- **Сезоны** — зима/весна/лето/осень меняют вероятности событий и расходы
- **15 событий** (вместо 5)
- **Сохранение/загрузка** — localStorage, слоты
- **Интерактивные баблы** — клик по баблу жильца показывает карточку; баблы показывают реплики при событиях
- **Визуальная связь** — при состоянии < 50 на фасаде появляются трещины; улучшения меняют цвет крыши / добавляют элементы
- **Панель жильцов** — список всех квартир и жильцов с возможностью выселения
- **Кнопка ремонта** — самостоятельное действие игрока (не только событие)
- **Журнал** расширен до 50 записей

## 3. Персонал дома

Три должности. Каждую можно **нанять** (единоразово 20 ₽) и **уволить** (безплатно, но –3 репутации).

| Должность | Жалованье (₽/ход) | Эффект |
|-----------|---------------------|---------|
| **Дворник** | 10 | +1 состояние/ход, убирает снег (зимой без него –3 состояния) |
| **Управляющий** | 25 | Снижает шанс негативных событий на 20%, авто-сбор квартплаты (+5% к сбору) |
| **Швейцар** | 15 | +3 репутация/ход, отваживает подозрительных (снижает шанс «Скандала» и «Краж») |

### 3.1. UI персонала

Отдельная вкладка/панель «Персонал»:
- Три строки: должность, занята/вакантна, кнопка «Нанять» / «Уволить»
- Стоимость жалованья показана
- Эффект описан текстом
- Если вакантна — серая иконка, если занята — золотая

## 4. Улучшения дома (Upgrades)

Разовыя покупки,永久ный эффект. Требуют денег и, возможно, условий.

| Улучшение | Цена | Условие | Эффект |
|-----------|------|---------|---------|
| **Ремонт фасада** | 300 ₽ | — | +30 состояние (разово) |
| **Новая крыша** | 500 ₽ | — | +25 состояние, защита от протечек на 12 ходов |
| **Водопровод** | 600 ₽ | — | +10 репутация, +15% к квартплате всех жильцов |
| **Газовое освещение** | 450 ₽ | — | +8 репутация, +10% к квартплате |
| **Брандмауэр** | 250 ₽ | — | Защита от пожара (событие «Пожар» наносит вдвое меньше урона) |

Улучшения сохраняются в `state.upgrades: string[]` (массив id).

### 4.1. UI улучшений

Панель «Улучшения»:
- Список доступных улучшений
- Купленныя — отмечены галочкой и недоступны
- Недоступныя (не хватает денег) — серая кнопка
- Кнопка «Купить» с ценой
- При наведении — описание эффекта

## 6. Сезоны

Каждые 3 хода меняется месяц. Сезон вычисляется из месяца:

| Сезон | Месяцы | Модификаторы |
|--------|--------|-------------|
| **Зима** | XII–II | +15 ₽ расходов (дрова), дворник обязателен (без него –3 состояния/ход) |
| **Весна** | III–V | +15% к шансу «Новый жилец» (переезды), +10% «Наводнение» |
| **Лето** | VI–VIII | +20% «Белыя ночи» (особое событие), художники платят +25% |
| **Осень** | IX–XI | +10% «Протечка», +5% «Наводнение» |

## 12. Рефакторинг из Итерации 1

### 12.1. EventSystem → универсальный обработчик

В Итерации 1 события — простой массив. В Итерации 2 нужно:

- **Веса событий** — не все события равновероятны
- **Условные события** — выпадают только при выполнении условий (precondition)
- **Сезонные модификаторы** — меняют вероятность
- **Персонал модификаторы** — швейцар/управляющий меняют шансы

```typescript
interface GameEventDef {
  id: string;
  title: string;
  description: string;
  weight: number;                                    // базовый вес
  precondition?: (state: GameState) => boolean;      // условие выпадения
  seasonModifier?: Partial<Record<Season, number>>;  // множитель веса по сезону
  staffModifier?: Partial<Record<string, number>>;   // множитель от персонала
  requiresInput: boolean;
  choices?: EventChoice[];
  apply: (state: GameState, choice?: string) => EventResult;
}

function triggerEvent(state: GameState): GameEventDef | null {
  const available = EVENT_DEFS.filter(e => !e.precondition || e.precondition(state));
  const weighted = available.map(e => {
    let w = e.weight;
    if (e.seasonModifier?.[state.season]) w *= e.seasonModifier[state.season];
    // staff modifiers...
    return { event: e, weight: w };
  });
  // pick by weight
}
```

### 12.2. GameState — добавить поля

```typescript
interface GameState {
  // ... было
  staff: StaffMember[];          // нанятый персонал
  upgrades: string[];            // id купленных улучшений
  visualModifiers: VisualMods;   // флаги для рендерера фасада
  repairFlags: {                 // таймеры ремонта
    roofProtectedUntil: number;  // ход, до котораго защищена крыша
    pipesCleanedUntil: number;
  };
}

interface StaffMember {
  role: string;   // 'janitor' | 'manager' | 'doorman'
  hiredOn: number; // ход найма
}

interface VisualMods {
  showCracks: boolean;
  crackSeverity: number;    // 0..1
  roofColorBoost: boolean;
  showWaterPipes: boolean;
  showGasGlow: boolean;
}
```
