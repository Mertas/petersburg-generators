# Итерация 1 — Ядро: ход, жильцы, события

## Текущее состояние (реализовано)

Работающий MVP — пошаговый симулятор домовладельца в Петербурге XIX века.

### Механики

- **Случайный сид** генерируется при старте игры
- Дом стартует с **3 этажами × 5 осей = 15 квартир**
- **4 случайных жильца** уже заселены при старте
- **Квартплата**: каждый жилец платит 30–50 ₽/ход с шансом 70–90%
- **Расходы**: 25 ₽/ход (содержание + дворник)
- **5 случайных событий** с предусловиями
- **Износ**: при состоянии < 60 теряется 1 ед./ход
- **Поражение**: долг > 300 ₽ или состояние = 0

### Расширение этажей

- Кнопка **«Надстроить этаж»** — стоимость 2000 ₽
- Максимум 5 этажей (2 расширения от стартовых 3)
- При расширении: +5 квартир, +5 репутации, дом перестраивается

### Визуал

- **Баблы жильцов** — тёмные ярлыки с золотой обводкой у окон каждаго заселённаго жильца
- Фасад дома генерируется процедурно (Pixi.js v8)
- Панель ресурсов, журнал событий, кнопка хода — HTML/CSS поверх канваса

### Управление

- **Следующий ход** — основная кнопка (Enter)
- **Надстроить этаж** — кнопка расширения
- **PNG** — экспорт фасада
- Мышь: перетаскивание (pan), зум колёсиком
- R — сброс навигации

## Детали реализации (для справки)

### Стартовое состояние

| Параметр | Значение |
|-----------|----------|
| Деньги | 500 ₽ |
| Репутация | 50 |
| Состояние дома | 70 |
| Этажей | 3 |
| Осей | 5 |
| Квартир | 15 |
| Жильцов | 4 случайных |
| Месяц | Январь 1850 |
| Сид | случаен (1–999) |

### 5 событий

1. **Новый жилец** — принять/отвергнуть (только если есть свободныя квартиры)
2. **Неуплата** — случайный жилец не платит (только если есть жильцы)
3. **Мелкий ремонт** — починить (40 ₽) или отложить
4. **Жилец съезжает** — случайный жилец покидает квартиру
5. **Заклад** — найден свёрток (+60–100 ₽, если есть пустующая квартира)

### Расходы

| Статья | Сумма |
|--------|-------|
| Содержание дома | 15 ₽ |
| Дворник | 10 ₽ |
| **Итого** | **25 ₽** |

## Структура файлов

```
src/
├── types.ts              — HouseConfig, GameState, Tenant, Apartment, GameEventDef, LogEntry…
├── main.ts               — инициализация Pixi.js + игры, интеграция UI
├── game/
│   ├── GameState.ts      — createInitialState, expandFloors, canExpandFloors, randomSeed
│   ├── GameLoop.ts       — processTurnPhases, applyEventChoice
│   ├── EventSystem.ts    — triggerEvent (фильтр по предусловиям)
│   ├── events.ts         — 5 событий (EVENT_DEFS)
│   └── EconomyManager.ts — collectRent, calculateExpenses
├── ui/
│   ├── GameUI.ts         — DOM-панели: ресурсы, журнал, кнопка хода
│   └── EventModal.ts     — модальное окно события
└── house/                — существующий генератор фасада (без изменений)
```
