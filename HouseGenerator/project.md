## Обзор

Приложение генерирует фасад доходного дома в стиле петербургской эклектики XIX века по заданным параметрам:
- **Количество этажей** (3–5)
- **Сид (seed)** генератора для воспроизводимости
- Параметры дома: ширина, высоты этажей, тип кровли, балконы и т.д.

Результат — детализированный 2D фасад с:
- Цокольным этажом, парадным входом и несколькими жилыми этажами
- Окнами с наличниками, сандриками, ставнями и балконами
- Рустовкой, бриллиантовым рустом, филёнками
- Венчающим карнизом с модульонами, сухариками и розетками
- Кровлей (вальмовая / мансардная / двускатная) со слуховыми окнами, дымовыми трубами и флюгерами
- Водосточными трубами и анкерными связями

## Архитектура

Проект построен по **модульной архитектуре**, где каждый компонент отвечает за свою часть фасада:

```
                    ┌─────────────┐
                    │   main.ts   │  Инициализация, UI, навигация, рендер
                    └──────┬──────┘
                           │ config: HouseConfig
                           ▼
              ┌────────────────────────┐
              │   HouseGenerator.ts    │  Сборка всего дома
              └────────────────────────┘
               /    |    |    \    \
              ▼     ▼    ▼     ▼    ▼
    ┌─────────┐ ┌──────┐ ┌──────┐ ┌─────────┐ ┌──────────────┐
    │ Floor-  │ │Roof- │ │Porch-│ │ Decor-  │ │ Window-      │
    │ Renderer│ │Rend. │ │Rend. │ │ Factory │ │ Factory      │
    └─────────┘ └──────┘ └──────┘ └─────────┘ └──────────────┘
         │                                    │
         └──────────────┬────────────────────┘
                        ▼
              ┌──────────────────────┐
              │  drawPrimitives.ts   │  Графические примитивы
              │  colors.ts           │  Палитра и цветовые функции
              │  math.ts             │  RNG, математика
              └──────────────────────┘
```

### Принципы:
- **Seed-воспроизводимость**: mulberry32 RNG обеспечивает стабильный результат для заданного seed
- **Модульность**: каждый аспект дома (этаж, кровля, вход, окна) — отдельный рендерер
- **Иерархия Pixi.js**: компоненты группируются в `Container`'ы, которые добавляются в единый `worldContainer`

## Основные модули

### `types.ts` — типы и конфигурация

**Ключевые типы:**
- `HouseConfig` — полная конфигурация дома: стиль, этажи, оси, ширина, высоты, балконы, крыша, seed
- `HouseStyle` — `'eclectic'` (единственный текущий стиль)
- `RoofType` — `'mansard' | 'gable' | 'hipped'`
- `Palette` — цветовая палитра из 19 цветов (стены, русты, кровля, окна, чугун, золото, снег)
- `METER_TO_PX = 22` — коэффициент перевода метров в пиксели

**Стандартная конфигурация:**
```typescript
const DEFAULT_CONFIG: HouseConfig = {
  style: 'eclectic',
  floors: 4,
  axes: 5,
  widthM: 20,
  floorHeightsM: [2.5, 4.0, 3.6, 3.2, 2.9],
  balconyFloors: [2],
  hasAttic: false,
  roofType: 'hipped',
  seed: 42,
};
```

### `utils/math.ts` — математические утилиты

- **`mulberry32(seed)`** — детерминированный 32-битный генератор псевдослучайных чисел. Основа воспроизводимости.
- **`lerp(a, b, t)`** — линейная интерполяция
- **`clamp(value, min, max)`** — ограничение значения
- **`randRange(rng, min, max)`** — случайное число в диапазоне
- **`randInt(rng, min, max)`** — случайное целое
- **`pickRandom(rng, arr)`** — случайный элемент массива

### `utils/colors.ts` — работа с цветом

- **Базовые цвета**: 19 оттенков, отражающих материалы петербургской архитектуры (стена, руст, кирпич, кровля, чугун, золото, снег)
- **`getPalette(seed)`** — генерирует вариативную палитру (±5% по каналам) на основе seed
- **`varyColor(color, rng)`** — случайный сдвиг каждого RGB-канала
- **`lighten(color, factor)` / `darken(color, factor)`** — осветление/затемнение

### `utils/drawPrimitives.ts` — графические примитивы

Набор функций-обёрток над Pixi.js `Graphics` API:
- **`fillRect` / `strokeRect`** — залитый/обведённый прямоугольник
- **`hLine` / `vLine`** — горизонтальная/вертикальная линия
- **`fillPoly` / `strokePoly`** — полигон с заливкой/обводкой
- **`fillCircle`** — круг
- **`drawRustication`** — рустовка (имитация каменной кладки с кирпичной перевязкой)
- **`drawDiamondRust`** — бриллиантовый руст (ромбовидные вставки)

## Генерация дома

### `HouseGenerator.ts` — главный генератор

**`generateHouse(config?)`** — собирает полный `Container` с домом:

1. **Рассчитывает** межосевое расстояние и координаты оконных осей
2. **Отрисовывает этажи** снизу вверх (цоколь → 1-й → 2-й → …) через `renderFloor()`
3. **Добавляет венчающий карниз** через `drawMainCornice()`
4. **Отрисовывает кровлю** через `renderRoof()` с выбранным типом
5. **Добавляет водосточные трубы** по краям (левая и правая)
6. **Добавляет анкерные связи** (по 2 на этаж)
7. **Добавляет парадный вход** через `renderPorch()` по центральной оси

### `FloorRenderer.ts` — отрисовка этажа

**Интерфейс `FloorConfig`:**
- `level` — позиция (0 = цоколь)
- `widthPx`, `heightPx` — размеры этажа
- `windowAxes` — координаты осей окон
- `windowWidth`, `windowHeight` — размеры окон
- `hasBalcony`, `isPianoNobile`, `isBasement` — флаги типа этажа

**Процесс отрисовки:**
1. Заливка стены (цвет зависит от типа: цоколь / парадный / верхний)
2. Рустовка на парадном этаже (горизонтальные + вертикальные швы + бриллиантовый руст по углам)
3. Окна с вариативным стилем (форма арки, тип сандрика, количество импостов)
4. Балконы над окнами (плита, консоли, решётка с меандром или волной)
5. Межэтажная тяга (профилированный карниз с сухариками на верхних этажах)

## Визуальные компоненты

### `WindowFactory.ts` — фабрика окон

**Варианты окон (`WindowVariant`):**
- `semicircular` — полуциркульная (арочная) форма
- `rectangular` — прямоугольная
- `segmental` — лучковая (пологая арка)

**Композиция окна (8 слоёв):**
1. **Наличник** — профилированный, с «ушками» (выступами сверху и снизу)
2. **Ставни** — по бокам, с горизонтальными планками и петлями (опционально)
3. **Стекло** — с бликами (вертикальная полоса + диагональный отблеск)
4. **Рама** — внешняя + вертикальные импосты + фрамуга
5. **Подоконник-отлив** — основная плита + скат + металлический отлив с каплями
6. **Филёнка под окном** — декоративный прямоугольник с розеткой в центре
7. **Сандрик** (`triangular` / `segmental` / `rectangular` / `none`) — с консолями и элементами
8. **Замковый камень** — для арочных окон без сандрика

**Дополнительные функции:**
- `drawShopWindow()` — витрина магазина (чугунные столбы, вывеска с золотой рамкой)
- `drawDormer()` — слуховое окно (дормер) с треугольным фронтоном и круглым окошком

### `RoofRenderer.ts` — кровля

**Типы кровли (`RoofType`):**
- `gable` — двускатная (треугольный силуэт, фальцы, конёк)
- `hipped` — вальмовая (четырёхскатная, передний + боковые скаты, конёк с заглушками)
- `mansard` — мансардная (с переломом: крутой нижний скат + пологий верхний)

**Дополнительные элементы:**
- **Дымовые трубы** — кирпичные с поясками, карнизом, колпаком и флюгером
- **Слуховые окна** — дормеры с равномерным распределением
- **Парапет/балюстрада** — тумбы + балясины + поручень (опционально)
- **Флагшток/флюгер** — с выбором навершия (флаг / стрелка-флюгер / шар)
- **Снежные наносы** — волнообразные на карнизе (пасмурное питерское небо!)
- **Водосточные желоба** — по краям кровли

### `PorchRenderer.ts` — парадный вход

**Композиция (сверху вниз):**
1. **Козырёк** на ажурных чугунных кронштейнах (крепится к стене над архивольтом)
2. **Архивольт** — полуциркульная арка с замковым камнем
3. **Фрамуга** — полуциркульная с радиальной расстекловкой (9 лучей)
4. **Двустворчатая дверь** — филёнчатая, с ручками у центра, петлями по краям
5. **Табличка** с номером дома (стилизованные золотые цифры)
6. **Пилястры** по бокам с каннелюрами, базой и капителью
7. **Площадка + ступени** (3–5 ступеней) с расходящимися боковыми стенками
8. **Настенные фонари-бра** — чугунный кронштейн + стеклянный колпак со свечением

### `DecorFactory.ts` — архитектурный декор

- **`drawMainCornice`** — венчающий карниз: архитрав + фриз + модульоны + сухарики + верхняя плита
- **`drawGarland`** — лепная гирлянда с листьями и бантиком в центре
- **`drawMascaron`** — маскарон (стилизованное лицо: глаза, нос, рот, брови)
- **`drawRosette`** — лепная розетка (8 лепестков вокруг центра)
- **`drawWreath`** — лавровый венок с листьями и бантом
- **`drawDrainpipe`** — водосточная труба: воронка + труба + хомуты + отмёт
- **`drawAnchorPlate`** — анкерная связь (металлический диск с золотой буквой S)

## Навигация и экспорт

### Панорамирование и зум
Как на Яндекс.Картах:
- **Перетаскивание** мышью (pointerdown/pointermove/pointerup)
- **Зум колёсиком** с центрированием на курсор (мировые координаты остаются под мышью)
- Диапазон масштаба: 0.3x — 5x
- Курсор: `grab` / `grabbing`

**`applyTransform()`** применяет навигацию к `worldContainer` через `scale` и `position`.

### Экспорт в PNG
- Временно сбрасывает навигацию для чистого рендера
- Убирает фон (небо)
- Извлекает canvas через `app.renderer.extract`
- Скачивает файл `petersburg-house-[timestamp].png`

### Ресайз
- Отложенный debounce (150 мс) с перерисовкой дома под новый размер окна

## API и расширяемость

### Добавление нового стиля дома
1. Добавить значение в тип `HouseStyle` в `types.ts`
2. Создать отдельную функцию-генератор стиля в `HouseGenerator.ts` (или подпапку)
3. Реализовать вариации во всех рендерерах (`FloorRenderer`, `WindowFactory`, `DecorFactory`, `PorchRenderer`)

### Дочерние конфиги

**`FloorConfig`** — конфигурация этажа:
```typescript
interface FloorConfig {
  level: number;        // 0 = цоколь
  widthPx: number;
  heightPx: number;
  windowAxes: number[]; // X-координаты центров окон
  windowWidth: number;
  windowHeight: number;
  hasBalcony: boolean;
  isPianoNobile: boolean; // парадный этаж
  isBasement: boolean;
  style: 'eclectic';
  seed: number;
}
```

**`RoofConfig`** — конфигурация кровли:
```typescript
interface RoofConfig {
  widthPx: number;
  heightPx: number;
  type: RoofType;              // 'mansard' | 'gable' | 'hipped'
  dormersCount: number;        // количество слуховых окон
  chimneysCount: number;       // количество труб
  hasParapet: boolean;
  hasFlagpole: boolean;

```

**`PorchConfig`** — конфигурация входа:
```typescript
interface PorchConfig {
  centerX: number;

  doorHeight: number;
  style: string;
  hasTransom: boolean;   // фрамуга
```

**`WindowOptions`** — конфигурация окна:
```typescript
interface WindowOptions {

  mullions: number;               // количество вертикальных импостов (0–2)

```

## Заключение

Проект «Доходный дом» — это:
- **Процедурная генерация** фасадов с высокой степенью детализации
- **Seed-воспроизводимость** — один и тот же seed всегда даёт одинаковый дом
- **Модульная архитектура** с чётким разделением ответственности
- **Пиксельная графика** через Pixi.js без использования текстур (чистый `Graphics` API)
- **Стилизация под XIX век** — рустовка, бриллиантовый руст, лепнина, маскароны, венки, флюгеры

Подходит как основа для:
- Генератора архитектурных иллюстраций
- Образовательного проекта по истории архитектуры
- Инструмента для концепт-художников
- Дальнейшего расширения (другие стили, полноценная 3D-проекция, интерактивный редактор)
