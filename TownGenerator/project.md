# 2D Мультяшный Город — Санкт-Петербург XIX века (Pixi.js)

## Детальное техническое описание проекта

---

## 1. Общая концепция

Проект представляет собой **процедурный генератор 2D-фона** для платформера, действие которого разворачивается в стилизованном Санкт-Петербурге XIX века. Визуальный стиль — **мультяшный**: толстые контуры, упрощённые геометрические формы, яркие пастельные тона, мягкое градиентное освещение без фотореализма. Фон генерируется как **горизонтально бесшовная тайловая полоса**, пригодная для бесконечного скроллинга (параллакс-эффекта) в игре.

Генерация — **полностью процедурная**, без использования заранее заготовленных спрайтов зданий. Все элементы отрисовываются векторно через **Pixi.js Graphics API** и при необходимости кэшируются в `RenderTexture` для производительности.

## 5. Слойная архитектура (5 слоёв)

Фон строится как стек из **5 слоёв**, каждый из которых — отдельный `PIXI.Container`. Слои отрисовываются снизу вверх (от дальнего к ближнему):

### Слой 1: Небо (`SkyGenerator`)
- **Небесный градиент**: вертикальный линейный градиент от верхнего цвета к нижнему.
  - *Рассвет*: #FFB7B2 → #FFDAC1
  - *День*: #87CEEB → #E0F0FF
  - *Закат*: #FF7E67 → #F9A03F
  - *Ночь*: #0B1026 → #1B2A4A
- **Облака**: 3–15 штук (зависит от `density`) в верхней половине неба. Каждое облако — сгруппированные эллипсы/округлые прямоугольники с полупрозрачностью (alpha 0.3–0.7) и мягким белым/розоватым цветом. Облака генерируются с учётом бесшовности (крайнее левое облако может продолжаться на правом краю для стыковки).
- **Солнце/Луна** (опционально): диск в верхней части неба, с мягким свечением (glow-эффект через наложенный полупрозрачный круг большего радиуса). Положение по X случайно, но зафиксировано для одного сида.

### Слой 2: Дальние силуэты (`SilhouetteGenerator`)
- **Назначение**: создать эффект глубины, словно за основным рядом зданий есть ещё удалённые постройки.
- **Элементы**: упрощённые силуэты зданий, куполов (как у Исаакиевского собора), колоколен. Отрисовываются **только контурами** или полупрозрачной заливкой, цвет бледнее основного слоя, с альфа-каналом ~0.4–0.6.
- **Плотность**: при низком `density` (1–2) — 2–4 силуэта на тайл; при высоком (50+) — до 20+ мелких шпилей и куполов.
- **Стыковка**: как и в основном слое, заворачивается по горизонтали для бесшовности.

### Слой 3: Основные здания (`BuildingGenerator`) — **ключевой слой**
- Содержит непрерывный ряд зданий, занимающих всю ширину тайла по горизонтали, кроме промежутков (улиц, каналов, переулков).
- **Процесс генерации зданий** по шагам:
  1. **Разбиение ширины**: тайл делится на `N` участков случайной ширины (80–400 px). `N` зависит от `density`: чем выше плотность, тем больше узких участков, меньше широких проспектов.
  2. **Переулки**: между участками оставляются зазоры (шириной 10–80 px, обратно зависит от `density`).
  3. **Генерация здания в каждом участке**:
     - Определяется `baseHeight` (40%–80% высоты холста) — базовая высота корпуса.
     - Выбирается `roofType` из доступных (зависит от стиля): в пикселях `roofHeight` = 0.1–0.4 × `baseHeight`.
     - Выбирается цвет фасада из палитры, соседние здания **не должны** иметь одинаковый цвет.
     - Генерируются окна: `windowRows` = floor(`baseHeight` / 40px), `windowsPerRow` = floor(`width` / 60px), с отступами от краёв.
     - Окна: прямоугольники с закруглёнными верхними углами (арки) или простые прямоугольники. В ночном режиме часть окон светится тёплым жёлтым.
     - Колонны: если `width > 200px` и `density > 2` — добавляются 2–4 колонны симметрично по фасаду (вертикальные прямоугольники с капителями).
     - Эркер: если `density > 5` и `width > 150px` — добавляется выступающий прямоугольник по центру фасада.
     - Балконы: декоративные горизонтальные выступы с узорными решётками (упрощённо — горизонтальная линия с вертикальными штрихами).
     - Купол: если `density > 3` и `width > 180px`, с вероятностью ~30% добавляется купол над крышей (полусфера или луковичная форма).
     - Шпиль: если `density > 4` и здание не имеет купола — тонкий треугольник или игла над крышей.
  4. **Карнизы**: декоративные горизонтальные выступы между этажами — количество растёт с `density`.
  5. **Фронтоны**: треугольные завершения над центральной частью широких зданий (в стиле классицизм).

- **Мультяшная обводка**: каждое здание обводится `outlineWidth`-пиксельным контуром цвета `outlineColor`.

### Слой 4: Уличные элементы (`StreetElementsGenerator`)
- Набережные, мосты, фонари, деревья. Этот слой располагается **перед** зданиями (поверх).
- **Элементы** (количество каждого пропорционально `density`):
  - **Фонари**: классические петербургские торшеры — вертикальный столб с горизонтальной перекладиной и круглым фонарём. Высота ~80–150 px. Расстояние между фонарями обратно зависит от `density`. В ночном режиме — свечение (полупрозрачный жёлтый круг) вокруг фонаря.
  - **Деревья**: упрощённые — коричневый ствол (вертикальный прямоугольник с небольшим утолщением книзу) и зелёная крона (круг или овал). Располагаются по краям улиц или вдоль набережной.
  - **Набережная**: гранитный парапет — горизонтальная полоса у нижней границы слоя BUILDINGS, состоящая из серых прямоугольных блоков с чередующимися тумбами.
  - **Мост**: если в промежутке между зданиями есть «вода» — может быть перекинут арочный мост (упрощённая дуга с перилами).

### Слой 5: Вода (`WaterGenerator`)
- **Расположение**: в нижней части экрана (нижние 20%–30% высоты холста).
- **Вода**: горизонтальная полоса с горизонтальными волнистыми линиями (синусоидальные кривые или зигзаги) для имитации ряби. Цвет: тёмно-синий/бирюзовый в зависимости от времени суток.
- **Отражения**: зеркально отражённые (перевёрнутые по Y, уменьшенная альфа ~0.3) упрощённые силуэты ближайших зданий и фонарей. Отражения смещены по вертикали с небольшим размытием (можно сделать через RenderTexture с alpha).
- **Каналы**: при наличии воды между зданиями (в промежутках, где ширина «зазора» превышает порог `waterThreshold`) — вертикальный прямоугольник воды, уходящий «вглубь» улицы (перспективная трапеция).

## 6. Параметр `density` — подробная механика

`density` — центральный управляющий параметр, влияющий **на все слои**. Он принимает значения от `1` до `Infinity`, но на практике в UI ограничен `1…100`.

### 6.1. Формулы влияния density

| Параметр                     | Формула при `density = d`                                    | Пояснение                                                     |
|------------------------------|--------------------------------------------------------------|---------------------------------------------------------------|
| Количество зданий на тайл    | `N_buildings = max(2, floor(4 + d * 2.5))`                  | Минимум 2 здания, растёт линейно                              |
| Ширина промежутков (переулков)| `gapWidth = max(10, 60 / d)`                                | Чем выше плотность, тем уже переулки                          |
| Вероятность эркера           | `P_erker = min(0.7, d / 15)`                                | 0% при d=1, 70% при d≥10.5                                    |
| Вероятность купола           | `P_dome = clamp(d / 25, 0.05, 0.6)`                        | 5% при d=1, растёт до 60%                                    |
| Вероятность шпиля            | `P_spire = clamp((d - 2) / 20, 0, 0.5)`                    | 0% при d≤2, 50% при d≥12                                     |
| Количество рядов окон         | `windowRows = max(2, floor(baseHeight / (50 - clamp(d, 0, 30))))` | Чем выше d, тем больше рядов (ближе друг к другу)       |
| Окон в ряду                  | `windowsPerRow = max(1, floor(width / (70 - clamp(d * 0.5, 0, 50))))` | Аналогично                                              |
| Количество фонарей           | `N_lamps = floor(2 + d * 1.2)`                              | Минимум 2 фонаря на тайл                                     |
| Количество деревьев          | `N_trees = floor(d * 0.8)`                                  | Минимум 0, растёт с плотностью                               |
| Количество облаков           | `N_clouds = floor(3 + d * 0.5)`                             | Минимум 3 облака                                             |
| Вероятность колонн           | `P_columns = min(0.8, d / 8)`                               | Требуется width > 200px                                      |
| Количество балконов на здание| `N_balconies = floor(d / 4)`                                | Распределены по этажам                                       |
| Детализация карнизов         | `N_cornices = max(1, floor(windowRows / 2) + floor(d / 3))` | Больше d → больше декоративных выступов                      |

### 6.2. Принцип «мультипликативного» влияния

`density` не просто добавляет элементы — он делает город **визуально насыщеннее**:
- При `density = 1`: редкие здания в стиле лаконичного классицизма, почти без декора, большие расстояния, 2–3 фонаря на весь тайл.
- При `density = 10`: плотный ряд зданий разной высоты, с окнами, балконами, несколькими куполами, фонарями через каждые ~150 px.
- При `density = 50+`: дворы-колодцы, узкие фасады с эркерами, шпилями, куполами, множество фонарей, деревьев, декоративных элементов — городская теснота.

## 7. Бесшовная стыковка тайлов

Горизонтальная бесшовность — одно из ключевых требований. Достигается следующими методами:

### 7.1. «Заворачивающиеся» координаты (wrapping)
- При генерации элементов, ширина которых выходит за правую границу тайла (например, здание начато на x=1700, width=400), остаток обрезается и **дублируется с левого края** с координатой `x_remainder - width`.
- Это делается для всех слоёв, включая облака, фонари, деревья.

### 7.2. Сид-ориентированная генерация
- Все генераторы используют **seeded PRNG** (простой линейный конгруэнтный генератор или `seedrandom`), который инициализируется из `CityGeneratorConfig.seed`.
- Для стыковки двух тайлов с одинаковым seed генерируется идентичный контент, что гарантирует стыковку.

### 7.3. Функция `wrapElement(elem, tileWidth)`
- Если `elem.x + elem.width > tileWidth`, создаётся копия элемента с `x' = elem.x - tileWidth`.
- Если `elem.x < 0`, копия с `x' = elem.x + tileWidth`.

### 7.4. Слой воды и отражений
- Вода генерируется как непрерывная горизонтальная полоса во всю ширину тайла. Волнистые линии также заворачиваются.

## 8. Палитры и освещение

### 8.1. Глобальная палитра
Палитра — объект `Palette`, выбираемый в зависимости от `TimeOfDay` и модифицируемый параметром `cartoonFactor` (при `cartoonFactor=1` цвета ярче и насыщеннее).

### 8.2. Цветовые схемы по времени суток

| Параметр          | Рассвет                     | День                  | Закат                    | Ночь                    |
|--------------------|-----------------------------|-----------------------|--------------------------|-------------------------|

| Небо (низ)         | `#FFDAC1` (персиковый)      | `#E0F0FF` (светло-голубой) | `#F9A03F` (золотой)  | `#1B2A4A` (синий)       |

| Крыши              | Серо-зелёные                | Серо-зелёные          | Тёмно-красные            | Тёмно-серые             |

### 8.3. Освещение окон
В ночное/закатное время окна заливаются `windowLightColor` (тёплый жёлтый `#FFD700`), и вокруг каждого светящегося окна добавляется мягкое свечение — полупрозрачный круг с радиальным градиентом (или просто круг с alpha).

### 8.4. Градиенты и тени
- Здания имеют лёгкий градиент (линейный сверху вниз) для имитации объёма: верхняя часть фасада светлее, нижняя — чуть темнее (на 5–15%).
- Тени от зданий и фонарей: упрощённо — не отбрасываются, но имитируются затемнением нижней части фасада.

## 9. Мультяшный стиль (cartoonFactor)

### 9.1. Контуры
- Каждый графический элемент обводится контуром `outlineWidth` px (по умолчанию 2–3 px).
- Контур темнее основного цвета на 30–40% (или фиксированный `outlineColor`).
- Реализация: для каждого визуального элемента сначала рисуется залитая форма, затем та же форма в режиме `lineStyle`.

### 9.2. Упрощённые формы
- Окна — простые прямоугольники с закруглёнными углами.
- Купола — полусферы (половина эллипса).
- Шпили — треугольники.
- Облака — сгруппированные круги/овалы.
- Деревья — ствол-прямоугольник + круг кроны.
- Фонари — прямоугольники + круг + линия.

### 9.3. Преувеличение пропорций (при `cartoonFactor` > 0)
- `cartoonFactor` влияет на соотношения:
  - Окна шире и выше на `factor * 20%`.
  - Купола более вытянутые (высота × `1 + factor * 0.5`).
  - Фонари крупнее.
  - Контур толще (`outlineWidth` × `1 + factor`).

## 10. Класс `CityGenerator` (`src/core/index.ts`)

### 10.1. Конструктор

```typescript
constructor(config: CityGeneratorConfig)
```

- Сохраняет конфигурацию.
- Инициализирует seeded PRNG из `config.seed || Date.now()`.
- Выбирает палитру на основе `config.timeOfDay`.

### 10.2. Главный метод `generate(): PIXI.Container`

```typescript
public generate(): PIXI.Container {
  const rootContainer = new PIXI.Container();

  const layerOrder = this.config.layers; // Учитываем порядок, заданный пользователем

  // Создаём слои в соответствии с порядком
  const generators: Record<LayerName, () => PIXI.Container> = {
    [LayerName.SKY]:                  () => this.skyGen.generate(),
    [LayerName.DISTANT_SILHOUETTES]:  () => this.silhouetteGen.generate(),
    [LayerName.BUILDINGS]:            () => this.buildingGen.generate(),
    [LayerName.STREET_ELEMENTS]:      () => this.streetGen.generate(),
    [LayerName.WATER]:                () => this.waterGen.generate(),
    [LayerName.FOREGROUND]:           () => this.foregroundGen.generate(),
  };

  for (const layer of layerOrder) {
    if (generators[layer]) {
      rootContainer.addChild(generators[layer]());
    }
  }

  return rootContainer;
}
```

### 11.3. Логика обновления (`src/playground/main.ts`)

```typescript
import { CityGenerator } from '../core/index';
import { Application, Container } from 'pixi.js';
import { createUI } from './ui';

async function init() {
  const app = new Application();
  await app.init({
    width: 1920,
    height: 1080,
    backgroundColor: 0x000000,
    antialias: true,
    resolution: window.devicePixelRatio || 1,
    autoDensity: true,
  });
  document.getElementById('pixi-canvas')!.replaceWith(app.canvas);

  let currentContainer: Container | null = null;

  function regenerate(config: CityGeneratorConfig) {
    if (currentContainer) {
      app.stage.removeChild(currentContainer);
      currentContainer.destroy({ children: true });
    }
    const generator = new CityGenerator(config);
    currentContainer = generator.generate();
    app.stage.addChild(currentContainer);
  }

  const ui = createUI(regenerate);
  // Первичная генерация с параметрами по умолчанию
  regenerate(ui.getConfig());
}

init();
```

### 11.4. Экспорт PNG
Используется встроенный метод Pixi.js: `app.renderer.extract.canvas(stage)` → `canvas.toDataURL('image/png')` → автоматическое скачивание через создание ссылки `<a download>`.

### 11.5. Горячая перезагрузка (HMR)
Vite обеспечивает HMR «из коробки». При изменении исходного TypeScript-кода страница обновляется автоматически, что ускоряет разработку и итерации над генераторами.

## 12. Генераторы — псевдокод и тонкости

### 12.1. `BuildingGenerator.generate()`

```typescript
generate(): PIXI.Container {
  const container = new PIXI.Container();
  const buildings = this.planBuildings(); // Шаг 1: разбиение на участки

  for (const bld of buildings) {
    // 2. Рисуем основной прямоугольник фасада
    this.drawFacade(container, bld);

    // 3. Рисуем крышу
    this.drawRoof(container, bld);

    // 4. Рисуем окна
    this.drawWindows(container, bld);

    // 5. Рисуем колонны (если есть)
    if (bld.hasColumns) this.drawColumns(container, bld);

    // 6. Рисуем эркер
    if (bld.hasErker) this.drawErker(container, bld);

    // 7. Рисуем балконы
    if (bld.hasBalcony) this.drawBalconies(container, bld);

    // 8. Рисуем купол/шпиль
    if (bld.hasDome) this.drawDome(container, bld);
    if (bld.hasSpire) this.drawSpire(container, bld);

    // 9. Карнизы и декор
    for (const deco of bld.decorations) {
      this.drawDecoration(container, bld, deco);
    }

    // 10. Обводка мультяшным контуром
    this.applyOutline(container, bld);
  }

  // 11. Wrap-элементы для бесшовности
  this.wrapContainer(container, this.config.width);

  return container;
}
```

### 12.2. Детали отрисовки

#### Фасад
- `PIXI.Graphics.rect(x, y + (canvasHeight - bld.height), bld.width, bld.height)` → `fill({ color: bld.color })`.
- Поверх заливки — лёгкий градиент: рисуется несколько полупрозрачных прямоугольников с изменяющимся альфа-каналом (или используется PIXI.FillGradient при поддержке v8).

#### Окна
- Расстояние между окнами по горизонтали = `bld.width / (bld.windowsPerRow + 1)`.
- Расстояние по вертикали = `bld.baseHeight / (bld.windowRows + 1)`.
- Каждое окно — `PIXI.Graphics.rect(...)` с закруглением верха (используется `arc` или `bezierCurveTo`). В ночном режиме — заливка жёлтым и свечение.

#### Купол
- Полусфера: `PIXI.Graphics.ellipse(cx, cy, radiusX, radiusY)`, обрезанная пополам по нижней границе крыши.
- «Луковичный» купол: составная фигура из дуги (`arc`) и треугольника — упрощённый силуэт.
- Цвет: золотой (`#FFD700`) / зелёный (`#5B8C5A`) / синий (`#4A6FA5`).

#### Шпиль
- Треугольник от центра крыши: `PIXI.Graphics.moveTo(cx, y_top); lineTo(cx - 5, y_base); lineTo(cx + 5, y_base); closePath()`.
- Тонкая игла: ширина 2–4 px, высота 20–60 px.

#### Эркер
- Выступающий прямоугольник по центру фасада: чуть светлее основного цвета, шире на 10–20 px с каждой стороны, с собственной маленькой крышей.

#### Колонны
- Вертикальные прямоугольники с уширениями наверху (капитель — маленький горизонтальный прямоугольник) и внизу (база).

#### Фонари
- Столб: `rect(x + 8, y - height, 4, height)`.
- Перекладина: `rect(x - 6, y - height, 16, 3)`.
- Фонарь: `circle(x + 8, y - height - 5, 7)` с заливкой жёлтым и свечением (полупрозрачный круг радиусом 15 px).

#### Деревья
- Ствол: `rect(x, y - 60, 8, 60)` коричневого цвета.
- Крона: `circle(x + 4, y - 70, 25)` зелёного цвета.

## 13. Производительность и оптимизация

### 13.1. Кэширование в RenderTexture
Для статического фона (если параметры не меняются) результат генерации кэшируется:

```typescript
const renderTexture = PIXI.RenderTexture.create({ width, height });
app.renderer.render(container, { renderTexture });
const cachedSprite = new PIXI.Sprite(renderTexture);
```

Это позволяет заменить сложный `Container` с множеством `Graphics`-объектов на один `Sprite`, что радикально снижает нагрузку на рендеринг (особенно для мобильных устройств).

### 13.2. Повторное использование Graphics-объектов
Один и тот же `PIXI.Graphics` может переиспользоваться: очищаться (`clear()`) и перерисовываться при изменении параметров, вместо создания новых объектов.

### 13.3. Уровень детализации в зависимости от `density`
При `density > 30` можно упрощать мелкие детали (например, не рисовать отдельные кирпичи/рустовку, уменьшать количество граней в куполах), чтобы сохранить производительность.

### 13.4. Тайловый рендеринг
При использовании в игре с бесконечным скроллингом:
- Генерируется 2–3 тайла, которые переиспользуются (сдвигаются по кругу).
- Каждый тайл — отдельный `Sprite` из `RenderTexture`.
