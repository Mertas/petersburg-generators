# Petersburg Generators

Процедурная генерация Петербурга XIX века — три проекта (Pixi.js + TypeScript + Vite), каждый запускается отдельно:

| Проект | Что это |
|---|---|
| `House` | Библиотека-рендер доходного дома (фасады, эклектика) |
| `HouseGenerator` | Приложение: генератор процедурных доходных домов |
| `TownGenerator` | Генератор 2D мультяшного города-фона для платформера |

## Запуск

```bash
cd HouseGenerator   # или TownGenerator
npm install
npm run dev
```
